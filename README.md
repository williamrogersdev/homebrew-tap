# Homebrew tap for Mulchie

The menu bar app, which includes the `mulchie` command:

```sh
brew install --cask williamrogersdev/tap/mulchie
```

The command-line tool only (macOS and Linux):

```sh
brew install williamrogersdev/tap/mulchie-cli
```

Install one or the other: both provide the `mulchie` command. The files are rendered from the [Mulchie](https://github.com/williamrogersdev/mulchie) release assets.
